# Roadmap

Status: **Complete**, **Current**, **External gate**, or **Later**.

## Goal 0 — Foundation — Complete

Next.js 16 App Router, strict TypeScript, Tailwind, pnpm, ESLint/Prettier,
Vitest, Drizzle/Neon, Zod, QRCode, Lucide, schema, migrations, Git main branch.

## Goal 1 — Product map and docs — Complete

Canonical architecture, approved flow/wireframe, matchday design system,
implementation plan, route specs, operator runbook, agent guides, and log.

## Goal 2 — Local product MVP — Complete

Signed shared staff access; five removable local samples; pasted-name batches;
search/status/detail workspace; PNG invitation and QR pass; native share with
download fallback; manual sent marker; explicit review; atomic confirmation;
confirmed/used/invalid/unavailable/uncertain/session-expired behavior.

## Goal 3 — Production readiness — Current / external gate

- Provision approved Neon project and apply migrations.
- Set live HTTPS origin and stable secrets in hosting.
- Review hosting access logs for raw QR URL retention.
- Approve final event copy/artwork and real guest list.
- Test actual WhatsApp sharing on intended iPhone/Android phones.
- Scan printed/on-screen QR codes with event phones and rehearse weak network.
- Decide credential distribution, secret backup, event-day owner, and fallback.
- Deploy only after the above and rerun the operator rehearsal on the live URL.

## Later, not required for this event

Individual staff accounts/roles, password reset, delivery integration, CSV
import/export, in-app camera, offline redemption, audit history, analytics,
multi-event support, reissue tooling, and a general component catalogue.
