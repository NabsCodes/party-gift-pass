# Handoff Template

Use this when work stops before the current acceptance gate is complete.

## Outcome

- What is complete and usable now
- What is not complete

## Current Work

- Active roadmap goal
- Approved behavior or design decisions
- Work in progress that should not be rebuilt

## Files Touched

- Important paths only

## Checks Run

- Command and result
- Any skipped check and why
- Local result versus provider/deployed result

## Next Step

- The single highest-value next action

## Open Decisions or Blockers

- User decision, credential, provider, device, or external dependency required
